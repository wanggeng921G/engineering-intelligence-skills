# Grounded citations

Track each consequential claim with source title/URL or local path, revision/date, exact section/page/line/table, and what the source actually supports. Prefer manufacturer documentation, owner-issued standards, official API docs, primary research, and measurements from the user's system. Record retrieval date for changing content.

Check that every citation exists and supports the adjacent claim. Separate absolute maximum, recommended operating, and measured values; preserve units and conditions. Never infer a specification from a search snippet or cite a page not inspected. When primary access is unavailable, mark the claim unverified and name the needed document.

Cite important claims near the claim. For code cite path and line or commit. A source can be authentic yet fail to support the inference.
